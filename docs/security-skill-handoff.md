# Security skill handoff — manual, evidence-only (v1)

| Skill | Repository | Responsibility |
|---|---|---|
| Aegis | jussray/aegis | Defensive review and remediation |
| Sarissa | jussray/sarissa | Offline assessment planning and reporting |
| Medusa | jussray/medusa | Offline decision scrutiny |

Exchange only owner-approved, redacted evidence. Record origin skill/version, target ref, scope, evidence origin, evidence status, safe summary, approved evidence reference, observation time, unresolved checks, and owner decision. Missing scope or evidence means hold. A finding, hash or verdict never authorizes execution. No automatic cross-repository access, disclosure, testing, deployment or merge. Each skill retains its own definition and authority boundaries.
