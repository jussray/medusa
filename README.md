# Medusa

Standalone offline decision scrutiny. See [the preserved v1.1 skill](medusa-v1_1-SKILL.md), [version registry](registry/medusa.json), and [manual handoff](docs/security-skill-handoff.md). Existing ZIP artifacts are preserved; their contents and execution have not been verified. This registry does not authorize operations or certify runtime behavior.

## Archive integrity

The registry lists every tracked ZIP by its Git blob identity. CI checks exact byte identity and complete inventory coverage without opening or executing archive contents. This is preservation evidence only, not validation of any archived implementation.
